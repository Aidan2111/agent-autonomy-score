# Code of Conduct

This project is intended to be a useful, welcoming space for practical discussion about AI-assisted software delivery.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, and clarify before escalating.
- Keep criticism focused on ideas, code, and behavior.
- Respect boundaries around security reports and private information.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Public disclosure of private security reports before coordination.
- Spam, trolling, or repeated off-topic disruption.
- Sharing another person's private information without permission.

## Enforcement

Maintainers may remove comments, close issues, block accounts, or take other reasonable action to protect the project community.
